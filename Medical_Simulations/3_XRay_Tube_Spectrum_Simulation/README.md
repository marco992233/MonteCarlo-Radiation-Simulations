# X-ray Tube Spectrum Simulation

This project simulates the photon spectrum emerging from an X-ray tube using the Monte Carlo code PENELOPE (penmain). The results are validated against analytical spectra generated by the SpekPy v2 toolkit.

The simulations explore the effect of three key parameters on the emission spectrum:
*   **Electron Beam Energy ($E_0$):** Comparing a diagnostic energy (150 keV) with a mammographic energy (28 keV).
*   **Anode Material:** Comparing Tungsten (W) and Molybdenum (Mo) targets at 28 keV to observe characteristic K-line emissions.
*   **Geometry and Filtration:** Analyzing the beam-hardening effect caused by decreasing the anode tilt angle (from $45^\circ$ to $20^\circ$) and doubling the inherent aluminum filtration (from 1 mm to 2 mm).

## 📁 Repository Structure
*   **`Aplicaciones_Medicas_y_Industriales_de_las_Radiaciones__Tubo_X_ray.pdf`**: The complete report detailing the methodology, physical analysis, and comparison between PENELOPE and SpekPy.
*   **`input_decks/`**: Contains the PENELOPE/penmain input files (`.in`) for the 6 studied configurations, the geometric definitions (`.geo`) for the two tube setups, and the material files (`.mat`).
*   **`python_scripts/`**: Contains the Python script (`make_figures.py`) used to process the simulation data, compare it with SpekPy, and generate the final plots.
*   **`results_and_plots/`**: Contains the generated plots showing the simulated spectra and the comparisons with the analytical models.
